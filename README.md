# 台股觀察清單每日檢查工具

用 yfinance 抓日線，計算均線、RSI 等指標，用白話文給出訊號。
**只做資料分析，不會下單。訊號僅供參考，不是投資建議。**

## 安裝（只需做一次）

需要 Python 3.9 以上。在終端機進入本資料夾後：

```bash
python3 -m venv .venv                 # 建立獨立環境（Windows 同樣指令）
source .venv/bin/activate             # Windows 改用：.venv\Scripts\activate
pip install -r requirements.txt
```

## 執行（每天收盤後）

```bash
source .venv/bin/activate             # 每次開新終端機都要先做
python stock_checker.py
```

執行後會得到：
1. 終端機的摘要表（代號、名稱、收盤、離季線%、RSI、訊號）
2. `output/代號.png`：每檔一張 K 線圖（含 5/20/60MA 與成交量，紅漲綠跌）
3. `report.csv`：完整數字（含量比、距 52 週高點、持股損益），可用 Excel 開啟

## 修改設定（config.yaml）

- `watchlist`：要觀察的代號。上市/上櫃不用分，程式先試 `.TW` 再試 `.TWO`
- `names`：中文名稱（選填）
- `holdings`：你的持股（選填），格式見檔案內範例；有填才會檢查停損
- `stop_loss_pct`：停損比例，預設 `0.08`（8%）

門檻（過熱的 7%、RSI 75 等）在 `stock_checker.py` 最上方，可自行調整。

## 訊號意思

| 訊號 | 條件 |
|---|---|
| 多方 | 收盤在季線（60MA）之上，且季線比 5 天前高 |
| 站上季線但季線未向上，觀望 | 在季線之上，但季線還沒往上 |
| 轉弱，暫不買 | 收盤跌破季線 |
| 過熱，不追 | 單日漲幅 > 7% 或 RSI > 75 |
| 達停損 | 有持股，且收盤 ≤ 買進價 × (1 − 8%) |

訊號可能同時出現多個，例如「多方；過熱，不追」。

## 常見問題

- **某檔顯示 [錯誤]**：代號打錯、剛上市不到約 65 個交易日、或網路問題。其他檔不受影響。
- **中文顯示成方塊（圖上）**：安裝任一中文字型（Mac/Windows 內建的通常就可以）。
- **收盤價不是最新**：Yahoo 資料可能延遲，`report.csv` 的「資料日期」欄可確認。

## 選股器：每日／每週買進候選（screener.py）

```bash
python screener.py      # 產生 candidates_daily.csv、candidates_weekly.csv
python build_site.py    # 產生 site/index.html（網頁）
```

從上市＋上櫃「成交金額前 150 名」（自動抓，已排除 ETF 與你的觀察清單）挑出候選股，並算出：

- **買進價**：當日收盤價（建議不要追高超過 1%）
- **停損價**：近 10 日（週線用近 4 週）最低點下方 1%；跌破代表走勢失敗
- **停利價**：買進價 + 風險 × 2（賠 1 元要賺 2 元才值得）
- **理由**：白話文列出符合了哪些條件

| 條件 | 日線（每天） | 週線（每週六） |
|---|---|---|
| 趨勢向上 | 站上 60MA、60MA 向上、20MA > 60MA | 站上 13 週線、13 週線向上、10 週線 > 13 週線 |
| 不過熱 | RSI 45~70，單日漲幅 < 7% | RSI 50~72，單週漲幅 < 15% |
| 強勢 | 距 52 週高點 ≤ 15% | 距 52 週高點 ≤ 12% |
| 進場型態 | 回測 20MA（高於均線 0~4%）或突破 20 日高點且量 ≥ 1.5 倍 | 回測 10 週線（0~6%）或突破 8 週高點且量 ≥ 1.2 倍 |
| 停損幅度 | 3%~8%，超過就不列 | 4%~12%，超過就不列 |

門檻都在 `screener.py` 最上方，可自行調整。沒有符合的股票時清單會是空的，這是正常的。

**這是規則篩選，不是預測，也不保證獲利。** 買進前請自己看過 K 線、新聞與大盤狀況。

## 自動更新網頁（GitHub Pages）

`.github/workflows/daily.yml` 會在週一到週六台灣時間 15:00 自動執行分析與選股並更新網頁，
也可以到 GitHub 的 Actions 頁面手動按 Run workflow。
